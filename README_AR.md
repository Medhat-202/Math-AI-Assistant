# Math AI Assistant — نسخة أولية

مشروع Android Studio تجريبي بنافذة عائمة. يلتقط صورة للشاشة عند الضغط على «اقرأ الآن»، ثم يستخدم ML Kit OCR لقراءة النص ويحاول حساب العملية أو مقارنة الطرفين.

## التشغيل
1. فك ضغط الملف وافتح مجلد `MathAIAssistant` في Android Studio.
2. انتظر Gradle Sync، ثم شغّل التطبيق على هاتف Android.
3. اضغط «السماح بالنافذة العائمة» وفعّل الإذن.
4. ارجع للتطبيق واضغط «تشغيل المساعد»، ثم وافق على مشاركة الشاشة.
5. افتح لعبة التدريب واضغط «اقرأ الآن» لقراءة المسألة الحالية.

## حدود النسخة
- هذه ملفات مصدرية أولية وليست APK جاهزاً.
- القراءة تتم عند الضغط على الزر، وليست مراقبة مستمرة.
- يدعم المحرك + و - و * و / والأقواس والمقارنات < و > و =.
- دقة OCR تعتمد على وضوح المسألة، وقد تحتاج بعض الشاشات إلى تحسين.
- التطبيق لا يضغط أزرار اللعبة ولا يرسل إجابات نيابة عنك.
- مشاركة الشاشة والنافذة العائمة تتطلبان موافقتك ويمكن إيقافهما بإغلاق النافذة.
